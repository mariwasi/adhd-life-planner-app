# ADHD Life Planner App

A brain-friendly daily planning web app for ADHD minds. Fully offline — all data stays in the browser (localStorage).

## What it does
- Top 3 — pick just three priorities for today
- Brain Dump — get every thought out of your head
- Break It Down — split a big task into small steps
- Focus Timer — 5, 15 or 25 minute focus sessions
- Routines — simple daily routines
- Wins — record the small wins

## Use it
Open `index.html` in any browser. No build step, no server, no account.

Live: https://adhd-life-planner-app-moneyos2.vercel.app/
